Project Overview

Raw transaction data can contain valuable information, but visual dashboards make important patterns easier to identify and communicate to stakeholders.

This project transforms the Amazon sales dataset into interactive dashboards using two commonly used data visualization tools: Microsoft Excel and Power BI.

Dashboard Analysis

1. Amazon Sales Dashboard using Microsoft Excel

Microsoft Excel

An Excel dashboard was created to summarize key sales performance indicators and explore patterns across categories, products, customers, and time.

Key Insight:

The dashboard provides a concise overview of sales performance and allows users to explore important business metrics through interactive Excel visualizations.

2. Amazon Sales Dashboard using Power BI

Microsoft Power BI

A Power BI dashboard was developed to provide interactive analysis of revenue, orders, customers, products, payment methods, geographical distribution, and monthly sales trends.

Key Insight:

The Power BI dashboard highlights overall revenue performance, product contribution, payment preferences, geographical sales, and monthly revenue trends.

Conclusion

This project demonstrates how data visualization can transform raw transactional data into clear and actionable business information.

By combining Microsoft Excel and Power BI, the analysis presents sales performance, customer behavior, product performance, payment preferences, geographical distribution, and sales trends in an accessible dashboard format.
