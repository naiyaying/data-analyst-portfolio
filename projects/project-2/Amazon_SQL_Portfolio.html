Project Overview

Businesses generate enormous amounts of transaction data every day. However, raw data alone cannot support decision-making unless it is transformed into meaningful business information. This project focuses on analyzing an Amazon e-commerce dataset using SQL to uncover valuable insights from sales, customers, products, operations, geography, and time-based performance.

Throughout this project, SQL was used to perform data exploration, aggregation, filtering, grouping, ranking, and trend analysis. A total of 23 business questions were answered to simulate real-world business reporting and demonstrate practical SQL skills commonly required for Data Analyst roles.

Instead of simply displaying SQL syntax, this project emphasizes business interpretation by explaining what each analysis means and how the results could help stakeholders make better business decisions.

Featured SQL Analysis

Below are several business questions answered using SQL. Each analysis includes the business question, SQL query, query result, and a brief business insight.

1. Total Revenue

Business Question

How much total revenue was generated from all transactions?

SQL Query 

SELECT
    SUM(TotalAmount) AS Total_Revenue
FROM amazon;

Result

$91.83M

Business Insight

The company generated more than $91.83 million in revenue, providing a strong foundation for evaluating overall business performance.

2. Total Transactions

Business Question

How many transactions occurred during the analysis period?

SQL Query 

SELECT
    COUNT(*) AS Total_Transactions
FROM amazon;

Result

100,000

Business Insight

The dataset contains 100,000 transactions, making it large enough to identify meaningful business patterns and trends.

3. Average Order Value

Business Question

What is the average transaction value?

SQL Query 

SELECT
    AVG(TotalAmount) AS Average_Order_Value
FROM amazon;

Result

$918.26

Business Insight

On average, each customer transaction generated approximately $918.26, indicating relatively high purchase values.

4. Highest Revenue Category

Business Question

Which product category generated the highest revenue?

SQL Query 

SELECT
    Category,
    SUM(TotalAmount) AS Revenue
FROM amazon
GROUP BY Category
ORDER BY Revenue DESC;

Result

Electronics

Business Insight

Electronics generated the highest revenue, making it the company's strongest performing product category.
